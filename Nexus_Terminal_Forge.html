Privacy and publishing

This generator keeps project content in memory until you export it. No automatic storage, account or telemetry. Repository discovery calls GitHub's public API only when requested. Embedded artwork travels with the HTML; remote image URLs require browser networking. Visitors to the generated terminal can separately opt into repository image lookups and local `.udata` persistence.
